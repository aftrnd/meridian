# Security

Please report security problems privately, never in a public issue.

- **On GitHub:** use **Report a vulnerability** on this repository's [Security tab](https://github.com/aftrnd/meridian/security/advisories/new).
- **By email:** support@nejack.com

This covers Meridian (the app and its engine), the build scripts in this repository, https://meridian.nejack.com and the license service behind it.

Please say what you found, how to reproduce it, and which Meridian and engine versions you used (Meridian › Settings › Updates shows both). Leave out license keys, Steam logins and other personal data unless the problem can't be shown without them.
